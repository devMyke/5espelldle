# 5eSpellDLE

A daily guessing game for D&D 5e spells (SRD 5.1). Plain HTML, CSS and JavaScript: no build step, no server.

## Files

| File | What it does |
|---|---|
| `index.html` | Page structure |
| `style.css` | Look and layout |
| `game.js` | Game rules, daily spell, saving progress, sharing |
| `spells.js` | The 319 SRD spells, generated by the script below |
| `tools/build_spells.py` | Rebuilds `spells.js` from the 5e-database project |

## Play it locally

Open the folder in VS Code, right-click `index.html` and choose **Open with Live Server**.
(Double-clicking `index.html` also works.)

## Put it online with GitHub Pages

1. In VS Code, open the **Source Control** panel (Ctrl+Shift+G).
2. Type a message such as `First version`, click **Commit** (choose "Yes" if asked to stage all changes), then click **Sync Changes**.
3. On github.com, open your repository, go to **Settings → Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, and click **Save**.
5. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/5espelldle/`.

Every later commit + sync updates the live site automatically.

## Things you can tweak (top of `game.js`)

- `LAUNCH`: the date of puzzle #1. Set it to the day you go live.
- `MAX_GUESSES`, `CLUE_AFTER`: number of slots, and when the clue unlocks.
- `SHUFFLE_SEED`: changes the order of every future answer. Don't change it after launch.

Changing the spell list also changes the daily order, so avoid that after launch too
(or only ever append new spells to the end).

## Rebuilding the spell data

```
git clone --depth 1 https://github.com/5e-bits/5e-database.git
python tools/build_spells.py 5e-database/src/2014/en/5e-SRD-Spells.json
```

Fix individual spells in the `OVERRIDES` table in the script.
